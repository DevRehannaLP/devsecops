# The Anatomy of a Git SSH URL

- <git@github.com>:USERNAME/REPO.git
  - |....|............|......|
  - |....|............|......└─ repo name + .git
  - |....|............└─ your GitHub account/org
  - |....└─ the real host
  - └─ you ALWAYS log in as the user "git", never your own name
